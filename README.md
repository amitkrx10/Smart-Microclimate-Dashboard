An interactive Streamlit dashboard that visualizes environmental sensor data (temperature, humidity, etc.) stored in a SQLite database.

🚀 Features

Real-time microclimate data visualization

Interactive Plotly charts

Fast data loading with caching

Local SQLite storage

⚙️ Setup
pip install -r requirements.txt
streamlit run streamlit_dashboard.py

📊 Data Source

Sensor readings are stored in microclimate.db and retrieved for visualization.

🧰 Tech Stack

Python · Streamlit · Plotly · Pandas · SQLite3
